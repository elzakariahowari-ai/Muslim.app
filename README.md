# تطبيق MUSLIM - أندرويد

تطبيق إسلامي كامل يحتوي على القرآن الكريم (قراءة وصوت)، مواقيت الصلاة بالمغرب، أذكار ومسبحة رقمية.

## طريقة التحويل إلى APK عبر GitHub Actions:
1. قم بفك الضغط عن هذا الملف (`muslim_app_project.zip`).
2. قم برفع كافة المحتويات إلى مستودع جديد (Repository) على حسابك في GitHub.
3. افتح تبويب **Actions** في مستودعك على GitHub وسيعمل البناء تلقائياً لتوليد ملف الـ APK.
4. حمل ملف الـ APK الجاهز مباشرة من قسم **Artifacts**.
